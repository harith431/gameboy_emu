# Game Library

Drop `.gb` / `.gbc` ROM files in this folder to make them appear in the
emulator's library screen.

You can also import ROMs from inside the emulator: press **I** in the library
screen and pick a file with the built-in file browser.

ROM files are **not** tracked by git (see the top-level `.gitignore`) — only
this README is committed. Put your own legally-obtained ROMs here.
